工場の購買業務を、AI とともにまるごと代行します。

試用版（Windows 10 / 11）のダウンロードページです。

1. インストーラーをダウンロード

Windows 版をダウンロード ChuoSogo-Setup.exe ・ 約 {{MB}} MB ・ バージョン {{VERSION}}

インストール後、アプリの中から AI などの追加データ（合計 約10.8 GB）を入れます。

2. インストールと最初の設定

  1. ダウンロードした ChuoSogo-Setup.exe を開きます。
    「Windows によって PC が保護されました」と表示されたら、「詳細情報」→「実行」を押してください（試用版のため署名がありません）。
  2. 画面の案内に沿ってインストールし、Chuo-Sogo Procure を起動します。
  3. 使い方を選びます。
    • サーバーに接続する：試用サーバーにつながります。サインイン画面の役割ボタンで、工場の担当者・承認者・当社スタッフとして試せます。
    • この PC だけで使う：サーバーもインターネットも不要で、PC 1台で全機能が動きます。
  4. 「この PC だけで使う」を選んだ場合、追加データの画面で「インストール」を押します。PC のメモリに合わせて、高精度 AI（約9 GB、メモリ16 GB以上）か軽量 AI（約5 GB、8 GB以上）をおすすめします。

Download for Windows

ChuoSogo-Setup.exe · about {{MB}} MB · version {{VERSION}} · Windows 10/11 (64-bit)

  1. Open ChuoSogo-Setup.exe. If Windows says "Windows protected your PC", choose "More info" → "Run anyway" (the trial is not signed).
  2. Install and start Chuo-Sogo Procure.
  3. Choose Connect to a server (the trial server; use the role buttons on the sign-in screen) or Use on this PC only (everything runs on this PC, no server or internet needed).
  4. In "this PC only" mode, install the additional data from inside the app (about 10.8 GB): the high-accuracy AI for PCs with 16 GB of memory, or the light AI for 8 GB.
