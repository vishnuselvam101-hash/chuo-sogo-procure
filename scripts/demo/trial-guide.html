Chuo-Sogo Procurement Platform — Trial guide (version 1.0.0)

見積依頼から承認・発注・請求書までを一つのアプリで管理する業務用ソフトです。インストールするだけで試用サーバーにつながります。表示されるデータはすべて架空のデモデータです。
Install the app and it connects to the trial server automatically. All data is fictional demo data.

1. インストール Install

このフォルダの中から、お使いの端末のフォルダを開いてください。接続先の設定は不要です。

Windows: if SmartScreen appears, click “More info” → “Run anyway”. Mac: right-click the app → Open the first time. The warnings appear because the trial is not yet code-signed.

3. 試してほしいこと What to try

約30分で、依頼から請求書までの流れを一通り体験できます。

A. 顧客企業（サンプル精機）

  1. requester でサインイン →「調達依頼」。提出済みの「ライン3 ベアリング交換部品」と下書き「安全手袋・消耗品」があります。下書きを開いて提出してみてください。
  2. manager でサインイン →「承認」。内容を確認して承認または差し戻し。承認できるのは人だけで、AIは承認も発注もしません。
  3. finance でサインイン →「中央総合からの請求書」。インボイス制度対応の請求書をPDFで保存できます。
  4. ceo でサインイン →「メンバー管理」「監査ログ」。誰がいつ何をしたかがすべて残ります。

B. 中央総合の調達担当

  1. operator でサインイン →「業務キュー」。顧客から届いた依頼が並びます。
  2. 「見積依頼 (RFQ)」「見積書」で仕入先の見積を比較します。試用版では仕入先へのメールは実際には送信されません。

C. 仕入先（大阪ベアリング）

  1. sales でサインイン →「製品掲載」。写真・型番・仕様付きの製品が並んでいます。
  2. 新しい製品を作り、AIアシストにカタログのPDFやExcelを渡すと、型番や仕様の入力案が出ます。採用するかは人が決め、入力済みの項目は上書きされません。

D. 一般のお客様（Shopアプリ）

  1. hanako でサインイン。税込価格の商品一覧からカートに入れ、注文します。
  2. 「ご注文履歴」で請求書付きのデモ注文を開き、振込先と請求書PDFを確認します。
  3. 「特定商取引法に基づく表記」はサインイン前から見られます。

4. 注意事項 Notes

  • 試用サーバーのデータはすべて架空です。実際の発注・請求・メール送信は一切行われません。
  • 自由に操作してかまいません。デモデータはこちらで初期化できます。
  • 本物の社内情報や個人情報は入力しないでください。
